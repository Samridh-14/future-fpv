WHATSAPP ORDER REGISTER

Monitor your orders.

Open WhatsApp ↗

After a customer sends an order on WhatsApp, add it here to track its progress. Orders are saved only in this browser, on this website address. GitHub Pages and the hosted preview have separate registers.

Customer orders do not appear here automatically. This public page has no secure login or shared order database. Your local entries are not uploaded to GitHub or visible to other visitors, but anyone using this browser profile can access them.
